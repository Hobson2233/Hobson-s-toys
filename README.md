# 校园网自动登录

校园网自动登录是一个面向郑航（郑州航空工业管理学院）校园网认证门户的自动认证工具，支持开机自动登录、多账号切换、断网自愈、密码框隐私保护与内置使用说明。单文件免安装，拷贝到任意 Windows 设备即可运行。

> 非官方项目，与学校网络管理部门无关。请仅使用你本人有权访问的账号，并遵守学校的网络使用规定。

当前版本 0.1.0，仍处于早期，功能与配置格式可能变动。下载见 [Releases](../../releases)。

![设置主界面](docs/main.png)

## 功能

- 开机自动认证，无需打开浏览器手动登录
- 多账号管理，一键切换；切换失败自动回滚到上一个可用账号
- 定时检测联网状态，掉线自动重连
- 密码框输入时只显示最后一位，可点按钮临时显示全文
- 使用说明内置于程序，无需另找文档
- 程序内不含账号密码，可直接分发给他人

## 运行环境

- Windows 10 / 11（x64）
- 无需安装 Python、VC++ 运行库或 .NET，依赖已全部打包进程序
- 磁盘占用约 10 MB

> 程序未进行代码签名，首次运行会触发 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。这是 Windows 对未签名程序的默认策略，并非程序本身有问题。

## 下载与使用

仓库不存放构建产物，请从 [Releases](../../releases) 下载。Release 页面上显示为「校园网自动登录」，下载后的文件名为 `campus-login.exe`。

双击运行，填写学号与密码，点击「切换到此账号」。需要开机自动登录时，在设置页勾选「开机自启」。

账号与配置保存在 `C:\ProgramData\CampusLogin\`，不随程序文件移动，因此分发程序不会带走账号数据。程序可放在任意目录，含中文或空格的路径均可，且不依赖同目录下的任何文件。

> 例外是开机自启：自启快捷方式记录程序的绝对路径，移动程序后该功能会失效，取消并重新勾选「开机自启」即可恢复。

## 构建

需要 Python 3.9 及以上版本（需带 tkinter）。

```
pip install pyinstaller pefile
python build.py
```

`build.py` 依次执行以下步骤，任一步骤未通过则不出包：

1. 打包为单文件可执行程序
2. 冒烟测试，以及密码框接线自检
3. 隐私检查（`leak_check.py`）：解包确认程序内不含账号密码
4. 可移植性检查（`portability_check.py`）：确认依赖完整、未绑定本机构建路径
5. 复制到交付目录

第 3、4 步均带阳性对照，即先注入一个已知的坏样本，确认检查确实会报警。

开发脚本、测试清单与排障说明见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 适配其它学校

默认配置位于 `campus_login.py` 的 `DEFAULTS`：

```python
DEFAULTS = {
    "portalHost": "http://202.196.169.166",   # 认证门户地址
    "wlanAcIp":   "10.0.1.10",                # AC 地址
    "wlanAcName": "ZZHK-ZAX-BRAS",            # AC 名称
    "timeoutSec": 8,
}
```

认证协议为标准 `webauth.do` 表单提交。更换学校时用浏览器开发者工具抓取一次登录请求，按上述字段修改即可，也可直接修改数据目录中的 `config.json`。

## 隐私与数据

账号与配置保存在本机 `C:\ProgramData\CampusLogin\`；该目录不可写时自动回退到 `%APPDATA%\CampusLogin\`。程序内不含任何账号信息，请勿将账号数据分享给他人。

README 中的界面截图由 `ui_shot.py` 在隔离的数据目录中生成，图中显示的学号与密码均为编造的演示数据。

## 已知限制

- 程序未签名，首次运行会触发 SmartScreen 提示
- 仅针对郑航认证门户，其它学校需修改配置
- 界面为固定尺寸，不支持自由缩放
