# 校园网自动登录

校园网自动登录是一个面向郑航（郑州航空工业管理学院）校园网认证门户的自动认证工具，提供开机自动认证、多账号切换、断网自愈、密码框隐私保护与内置使用说明。

> 非官方项目，与学校网络管理部门无关。请仅使用你本人有权访问的账号，并遵守学校的网络使用规定。

当前版本 0.3.1，从 [Releases](../../releases) 下载。

![设置主界面](docs/main.png)

## 功能

- 开机自动认证，无需打开浏览器手动登录
- 多账号管理，一键切换；切换失败自动回滚到上一个可用账号
- 联网后继续守护 30 分钟，掉线自动重连；到点自动退出，不在后台常驻
- 状态栏区分「在校园网」与「能上网」：不在校园网时不会误报「已连接校园网」
- 密码框输入时只显示最后一位，可点按钮临时显示全文
- 内置检查更新，点标题栏的版本号即可升级到最新版；下载中断会自动重试，不用重头再来
- 使用说明内置于程序，无需另找文档
- 程序内不含账号密码，可直接分发给他人

## 运行环境

- Windows 10 / 11（x64）
- 无需安装 Python、VC++ 运行库或 .NET，依赖已全部打包进程序
- 单文件 exe，可放在任意目录运行，含中文或空格的路径均可，且不依赖同目录下的任何文件
- 磁盘占用约 12 MB

> 程序未进行代码签名，首次运行会触发 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。

## 下载与使用

本站在 [hobson2233.dpdns.org](https://hobson2233.dpdns.org) 提供下载，也可以在 [Releases](../../releases) 页面下载。

双击运行，填写学号与密码，点击「切换到此账号」。需要开机自动登录时，在设置页勾选「开机自启」。

账号与配置保存在 `C:\ProgramData\CampusLogin\`，不随程序文件移动。开机自启的快捷方式记录程序的绝对路径，移动程序后该功能失效，取消并重新勾选即可恢复；从旧版本升级上来时界面会提示「旧设置」，同样取消再勾一次，新的守护功能才会生效。

开机联网后程序还会继续运行 30 分钟，这期间检测到掉线会自动重连，到点自行退出，不会在后台常驻。若在这 30 分钟内主动点击「退出当前账号」，程序不会自动把你登回去。

程序会检查更新：点击标题栏右侧的版本号，有新版本时可直接下载并替换自身，账号数据不受影响。

## 构建

需要 Python 3.9 及以上版本（需带 tkinter）。

```
pip install pyinstaller pefile
python build.py
```

`build.py` 依次完成打包、冒烟测试、隐私检查与可移植性检查，任一步骤未通过则不出包。

发布站点时，把构建产物交给工作区根目录的 `make_site.py` 放进 `site/`，再由 `make_manifest.py` 生成更新清单，最后用 `deploy/deploy.py` 把 `site/` 发布到 Cloudflare Worker 的静态资源上。发布是**整份替换**：新版本目录里没有的文件，线上会直接消失（所以旧版安装包不会留在服务器上）。

开发脚本、测试清单与排障说明见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 适配其它学校

默认配置位于 `campus_login.py` 的 `DEFAULTS`：

```python
DEFAULTS = {
    "portalHost": "http://202.196.169.166",   # 认证门户地址
    "wlanAcIp":   "10.0.1.10",                # AC 地址
    "wlanAcName": "ZZHK-ZAX-BRAS",            # AC 名称
    "timeoutSec": 8,
}
```

认证协议为标准 `webauth.do` 表单提交。更换学校时用浏览器开发者工具抓取一次登录请求，按上述字段修改即可，也可直接修改数据目录中的 `config.json`。

## 隐私与数据

账号与配置保存在本机 `C:\ProgramData\CampusLogin\`，该目录不可写时回退到 `%APPDATA%\CampusLogin\`。程序内不含任何账号信息，请勿将账号数据分享给他人。
